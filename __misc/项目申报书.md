## 项目简介

moonsheet 是一个用 MoonBit 从零实现的**公式求值与依赖重算内核**，面向需要在 MoonBit 中构建
报表生成器、预算与财务模型、低代码表单规则、文档工具或教学演示的开发者。它解决的是
“改一格，只重算受影响的部分”这一层问题：公式解析、带类型的求值、错误传播、依赖图、
增量重算、跨工作表重算。文件格式与列式运算不是它的职责——这部分交给生态里已有的库。
核心库无平台依赖，native / wasm / js 三后端均可编译，上层应用只需提供 IO 与界面。

## 与生态中已有库的分工

MoonBit 生态已覆盖“文件格式”和“列式数据”两层，moonsheet 刻意只做二者都不负责的
“依赖传播与重算”层，并与它们组合使用，而不是重造。

| 能力 | `bobzhang/mbtexcel` | `ihb2032/MoonFrame` | moonsheet |
|---|---|---|---|
| XLSX 读写 | ✅ | — | ✅ 通过 `lib/xlsx` 适配器复用 `mbtexcel` |
| DataFrame / 列式运算 | — | ✅ | — |
| CSV 导入导出 | — | ✅ | ✅（仅作交换格式） |
| 公式解析（A1、区域、跨表） | — | — | ✅ |
| 带类型的求值与错误传播 | — | — | ✅（`#DIV/0!`、`#REF!`、`#N/A`、`#CIRC!` 等） |
| 依赖图、拓扑序、环检测 | — | — | ✅ |
| 增量重算（只算 dirty 子图） | — | — | ✅ |
| 跨工作表按依赖顺序重算 | — | — | ✅ |

一句话：**mbtexcel 搬字节，MoonFrame 搬列，moonsheet 搬依赖。** 典型链路是用 `mbtexcel`
读入工作簿，把值与公式字符串交给 moonsheet，重算后再写回——文件格式不需要由 moonsheet 拥有。

## 差异化的可验证证据

“增量重算”不是口号，可以用确定性的计数验证（`moonsheet bench`，不依赖机器性能）：

```text
bench: 200 rows, 400 formula cells (value -> formula -> formula chain)
  full recalculation         : 400 cells evaluated
  one value edit, incremental: 2 cells evaluated (0.5% of full)
  one formula edit           : 400 cells evaluated (graph rebuild)
  no edit                    : 0 cells evaluated

workbook: Assumptions!A1:A200 -> Income!B1:B200
  full recalculation         : 200 cells evaluated
  one assumption edit        : 1 cells evaluated (0.5% of full)
```

跨表场景按**单元格**失效：修改 `Assumptions!A100` 只把真正读取该格的下游公式标脏，而不是
整表重算。该行为有回归测试守护，也是文件格式库与 DataFrame 库都不提供的能力。

## 核心功能范围

- **值模型与错误语义**：`Number` / `Text` / `Boolean` / `Date` / `Error` / `Blank` 六种值，
  空单元格与空字符串区分；错误作为值传播（`#DIV/0!`、`#VALUE!`、`#REF!`、`#NAME?`、
  `#N/A`、`#NUM!`、`#CIRC!`），批量计算不会因单格出错而中断。
- **公式语言**：手写 lexer + Pratt parser + AST，支持数字、字符串、布尔、`A1` / `$A$1` 引用、
  区域 `A1:B2`、跨表引用 `Budget!D8` 与 `SUM(Budget!A1:B2)`、函数调用、括号、一元/二元运算、
  比较、`&` 连接与 `^` 幂运算，带明确的优先级与结合性。
- **函数库**：覆盖数学/统计、文本、逻辑、查找、条件聚合、日期、财务七类共 55+ 函数，
  包括 `SUM`、`AVERAGE`、`ROUND`、`COUNTIF`、`SUMIF`、`VLOOKUP`、`INDEX`、`MATCH`、
  `DATE`、`PMT` 等；`IF` / `IFERROR` 惰性求值，错误沿表达式传播。
- **依赖图与重算**：公式单元格维护 precedent / dependent 双向边；全量重算作为正确性基线，
  dirty 子图 + 拓扑排序作为增量路径；循环引用检测并标记 `#CIRC!`；区域依赖对
  ≤10,000 格的区域展开为单元格边。
- **工作簿与多工作表**：Workbook / Worksheet / Cell / Range / Address，稀疏单元格存储，
  工作表插入顺序固定，支持新增工作表与稳定标签页。
- **跨工作表引用与工作簿级重算**：表名大小写不敏感；按表间依赖做拓扑排序逐表重算，
  上游编辑自动驱动下游失效重算，跨表循环标记 `#CIRC!`，缺表返回 `#REF!`。
- **命名区域**：工作表级命名区域（如 `Sales = D2:D4`），求值与依赖图构建共用同一解析器，
  `=SUM(Sales)` 与 `=SUM(D2:D4)` 产生一致的依赖边。
- **数字格式**：General、固定小数（千分位）、货币、百分比；格式与值分离，编辑不丢失格式，
  JSON 往返保留格式。
- **互操作**：CSV 导入导出（含引号与换行转义）；类型保持的 JSON 工作簿格式
  （formula / kind / value / format）；XLSX 作为后续适配层。
- **命令行工具**：`eval`、`calc`、`json`、`validate`、`stress` 五个子命令，可用于快速验证与
  压力冒烟。
- **浏览器演示**：`web/` 以 MoonBit 驱动 DOM（`extern "js"`），提供网格编辑、公式栏、
  工作表标签与新增工作表、依赖高亮、错误着色、CSV 导入导出；内置 `Budget` / `Summary`
  两个工作表的跨表示例。
- **测试与 CI**：81 个单元/一致性测试，覆盖解析、公式打印往返、求值、错误、函数、日期、依赖图、
  命名区域、数字格式、增量重算、跨表按单元格失效、循环、CSV、JSON 与 XLSX 往返；GitHub Actions 三平台执行
  `check` / `test` / `fmt` / `info`。

## 预期目标与技术路线

以 MoonBit 作为唯一主实现语言，保持核心库无平台依赖，原生 / Wasm / JS 后端均可编译。
技术路线：先以值模型和错误传播定义清晰的语义边界，再用 Pratt parser 把公式文本转为 AST；
随后按“解析 → 引用收集 → 依赖图 → 拓扑重算”的链路跑通最小闭环，再叠加增量重算、
命名区域、跨表引用与数字格式；IO 与界面放在边界层，分别由 CSV/JSON 适配器与
MoonBit + JS FFI 的 Web 网格承担。正确性以公开表格语义为准，测试既覆盖单函数与表达式，
也覆盖跨模块的增量/全量一致性；性能上以稀疏存储与 dirty 子图控制重算范围。
目标是把项目做成边界清晰、可测试、可长期维护的 MoonBit 表格计算基础库。
